# Training V2 document builders

These builders produce the approved training spreadsheet and PDF from `battle-simulator/docs/training-approved-data.json`. The data is generated by `node battle-simulator/generate-training-approved-data.mjs`.

Set `GK_WORKSPACE` to the parent directory containing the `mllok` repository folder. Outputs are written to `outputs/approved_training_20261119/`.

- Spreadsheet: use the managed primary Node runtime and `@oai/artifact-tool`, with its node_modules symlink in a temporary build directory. Run `build_training_workbook.mjs`.
- PDF: use Python with PyMuPDF, pypdf and the Noto Arabic fonts available at `/usr/share/fonts/truetype/noto`. Run `build_training_pdf.py`.

The workbook was recalculated and compared against the training engine in 1,605 checks. LibreOffice rendering was used to verify Arabic text. Microsoft Excel itself was not opened. The PDF was visually reviewed across all nine pages.

The source image statistics and six resource budgets come from the owner. Siege pricing and time, the 80% reduction distribution, and gold conversion are marked as proposals. These files are not a production game deployment.
