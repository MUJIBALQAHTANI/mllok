# Training V3 document builders

These builders produce the approved training spreadsheet and PDF from `battle-simulator/docs/training-approved-data.json`. The data is generated by `node battle-simulator/generate-training-approved-data.mjs`.

Set `GK_WORKSPACE` to the parent directory containing the `mllok` repository folder. Outputs are written to `outputs/revised_training_20261119/`.

- Spreadsheet: use the managed primary Node runtime and `@oai/artifact-tool`, with its node_modules symlink in a temporary build directory. Run `build_training_workbook.mjs`.
- PDF: use Python with PyMuPDF, pypdf and the Noto Arabic fonts available at `/usr/share/fonts/truetype/noto`. Run `build_training_pdf.py`.

The workbook builder recalculates and compares its formulas against the training engine. See `workbook-verification.json` for the current check count and `pdf-verification.json` for the PDF layout result. LibreOffice rendering verifies Arabic text; native Microsoft Excel is not opened. The V3 PDF adds the complete building batch-limit table and combined time reductions.

V3 applies the owner's 70% base reduction to every unit's reference resources and time, preserving fractional bases until the documented final rounding. The previous building curve then reduces the new time by up to 80%, for a combined 94% reduction against the same-forge V2 reference. Batch limits use the supplied building screenshots: 300/150/75 at level 1, growing by floor(base * 1.25^(level - 1)). The images' old speed percentages, prices and conflicting unlock levels do not replace the previously approved rules. Combat, forge factors, movement, cargo and the 96-second gold conversion remain unchanged. These files are not a production game deployment.
